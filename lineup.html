Depth & lineup schema

The field-by-field schema for player availability evidence, and the precise limit of what a published depth order can tell you about a replacement.

Schema before data. A lineup model must keep four things apart: a report state, a confirmed active status, a published depth order and an expected workload. Collapsing them is how a depth chart turns into a false pick. The table below specifies the fields; it does not fill them in.

02 / DEPTH STRINGS

Second, third and fourth string

The specific deficiency this project has to detect.

WHAT EXISTS

Published order inside a position group

Club charts publish a first, second and third name inside each position group. In the verified Commanders chart, running back reads Jacory Croskey-Merritt, Rachaad White, Austin Ekeler, and quarterback reads Jayden Daniels, Marcus Mariota, Athan Kaliakmanis. That is a published order, not participation.

Open the club chart ↗
WHAT DOES NOT EXIST

Confirmation of who starts or plays

No official source in this repository confirms a starter, an assignment or an expected snap count for a player who replaces an unavailable starter. A depth rank plus an injury status is evidence of a gap, not a forecast.
