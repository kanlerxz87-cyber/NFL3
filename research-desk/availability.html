Injuries and backup depth

Which starters are out, who is behind them on the official depth chart, and whether the market already knows.

How availability is measured. The official weekly injury report gives each player's game status (Out, Doubtful, Questionable). The same week's official depth chart gives each player's depth slot (1 = starter, 2/3/4 = backups). Joining them on player name and team-week produces "starters listed Out" per side of the ball — the input a replacement-quality model needs.

What is missing

  • Historical snap-share evidence for backups is fetched (2026 snap counts) but joining it to replacement performance needs a player-level graded dataset that is not in this snapshot.
  • Injury severity and expected games missed is not a field in the official report. Any estimate would be a model output and must be labelled as such.
  • The 2025 injury file exists but its depth chart uses the new schema without a week column, so the pooled window is 2021-2024 (1,139 graded games). 2025 is one pipeline run away.
