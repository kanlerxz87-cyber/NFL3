Official sources and verification register

Every computed number traces back to a file on this page, and every file was checked byte-for-byte against the SHA-256 digest GitHub publishes for that release asset.

Why a digest is sufficient. GitHub computes the digest server-side from the stored asset, so a match proves the local copy is identical to the official asset at the recorded time, not merely similar.

What "verified" does not mean

  • It does not mean the NFL's own feed is error-free. It means we copied the official asset faithfully and can prove it.
  • It does not survive a future refresh: a new asset gets a new digest. The timestamp column is the point-in-time reference.
  • Values that would need an official source we cannot reach are left blank and listed on Flagged for review .
