Method and limits

What was checked, and what this pass cannot claim

A verification pass is only as good as its boundary. This page states the boundary: which sources were opened, which were not, and what the checks can and cannot prove.

Method. Each cited official URL was opened directly in this session; published values were compared with what the page currently shows. No value was copied from a search result, and no value was adjusted, averaged or inferred. Where a published value could not be reproduced it is marked discrepancy, not corrected by guesswork.

Limits of this workspace

  • Static only. No live feed, no scheduled re-capture, no alerting; a value is only as fresh as its timestamp.
  • No source content was republished wholesale; observations are short factual restatements for review, and link rights are not implied.
  • Twenty-three captured club depth pages, the team directory, the rulebook, game-day preparation, AT spotters, calibration docs and the Pages documentation were not re-opened in this pass and are marked pending.
  • This pass did not edit any other session's files. Corrective changes are proposed on the suggestion queue.
  • Uncertainty is reported, never dismissed. No result on this site is presented as free of chance, opponent effects or model error.
