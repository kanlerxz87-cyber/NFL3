Controls and the removal of luck

Controls &amp; luck

The market benchmark, a random-pick control, a base-rate control and a favourites-only control — the floors a strategy has to clear before luck can be ruled out.

The four controls

  • C1 Market benchmark — the de-vigged closing price probability. It is scored with the same formulas, so the market is never assumed to be perfect.
  • C2 Random pick — 1,000 fixed seeds, a uniformly random side on every game, treated as a hard forecast. This is the luck floor for a rule with no information.
  • C2b Neutral — p = 0.5 everywhere. Its mean Brier score is exactly 0.25 and it is the information-free floor for a probability forecast.
  • C3 Favourites only — always take the shorter price. The luck floor for a staking rule.
  • C4 Base rate — the training-window base rate applied to every game: the floor for a rule with no per-game information.

Read the return column last. A positive realised return on this corpus is not evidence of skill: the random control reaches a positive 95th percentile on every market, so a lucky staking run and a real edge look identical in the return column. Only the signal columns above can tell them apart, and on this corpus the signal columns are negative for every registered row.
