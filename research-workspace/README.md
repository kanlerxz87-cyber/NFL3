# Supplemental NFL3 research workspace

This standalone static dashboard supplements the concurrently published root site. It documents a dated four-row injury excerpt, strategy hypotheses, validation gates, a proposed leaderboard, decision questions, and unresolved flags. It is not a live data feed, a betting model or a functioning competition. Numeric lines, correlations, results, rewards and replacement mappings are not verified.

Build and check with `python3 research-workspace/scripts/build.py` and `python3 research-workspace/scripts/check.py`. Serve the repository root with `python3 -m http.server 8000` and open `/research-workspace/`. The checker verifies internal links and the presence of official source links per table row; external content and availability require manual review.
