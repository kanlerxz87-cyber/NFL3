Overview

Dashboard

A decision-support build for originating NFL lines: verified inputs, an explicit model, and a register of everything that must be answered before a choice is made.

State of the project, stated plainly

Every data value on this site traces to an official NFL page. Every analytical number is produced by a script in the repository. And nothing here can be scored as a strategy yet, because the NFL does not publish its own lines — nfl.com/odds/ returns 404, and the odds shown in NFL widgets come from partner bookmakers with no archive — and no odds archive has been purchased. The leaderboard is empty because the evidence is absent, not because the work is unfinished.
