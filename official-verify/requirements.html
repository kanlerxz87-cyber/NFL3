How to read a "blocked" row. Blocked does not mean forgotten. Each row names the gate that stops it and the number that would clear it. Most are blocked by one missing input — a licensed price series, an official depth ordering, official snap counts, or a dated injury series — and unblocking any one of them would move several rows at once. The questions page records which questions unblock the most.
Nothing here is marked done on description alone. A row is "done" only when the mechanism exists in code or data and can be re-run. A row is "partial" when the mechanism exists but an input is missing. Anything that would need a guess is "blocked" rather than approximated, which is why the blocked count is large.
