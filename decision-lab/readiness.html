Decision readiness

Gate mapping is an operational summary of the current register, validator and pre-registration; it is not evidence that a model or betting strategy passed. A numeric target is supplied only where an existing check or written gate defines it. Unknown sample-size thresholds remain blank and are flagged.

Current boundary: no strategy, fair line, market residual, correlation estimate or reward is verified for deployment. A cleared site/build gate does not clear data, model or legal gates.
How to read the numeric column: a number appears only when a documented gate or a concrete completeness check supplies it. A blank numeric cell is intentional and accompanied by an explicit unverified note; do not substitute an estimate. Internal acceptance targets are project gates, not NFL facts. The pre-registered performance gates and validation-gate definitions state their provenance; a source link in a requirement row does not grant data reuse rights.
