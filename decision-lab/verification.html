Independent re-verification

Verification log

Every published value is re-checked against a second, independent transcription of the official page and against the page's own arithmetic. This is the line-by-line record. It runs without network access on purpose: a failed fetch must not be able to look like a passing check.

How to read a pass: a match means the published value equals the independent transcription. An unverified cell means no transcription exists for it, so this review makes no claim either way — it is not a soft pass.
Counted exceptions: 0 mismatches and 0 unverified values. Unverified values are listed individually below so they cannot be mistaken for confirmed facts.
