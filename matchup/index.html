THE MATCHUP DESK

Matchup deficiency desk

Which string is really on the field? A depth-of-replacement and offence-versus-defence workspace built only from official NFL pages and published club depth charts.

What this workspace is. One question, answered from published sources only: when a starter cannot play, which string takes his place, and which string does that string then face? Every number here is either copied from an official page or is an arithmetic difference between two copied numbers. Nothing is modelled, estimated or inferred. Where the answer is not published, the cell says so and names the reason.
