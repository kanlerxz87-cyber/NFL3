# Decision-readiness table — source and method notes

The generated table is embedded on the repository root landing page (`index.html`). It is generated by `scripts/build.py` from two inputs:

- `decision-lab/data/catalog.json`: canonical R01–R26 requirements, recorded state/evidence/next step, and source registry.
- `data/criteria.json`: proposed blocker mapping and clearance criteria. These are explicit project-policy proposals; they are not claims from the NFL or measurements of model performance.

Every matrix citation is the source ID already attached to that requirement in the canonical register. The matrix exposes the registered source's scope and limitation rather than substituting an unregistered citation. For R20, the registered policy page explains injury-status categories but does not verify game-day participation; the Game Book link and its reuse restriction are separately exposed on Flagged for Review.

Run:

```bash
python3 decision-readiness/scripts/build.py       # regenerate the root section
python3 decision-readiness/scripts/check.py        # fail closed on missing/mismatched rows, source hosts, gates, or thresholds
python3 scripts/validate_site.py                   # root CI validator invokes the readiness check
```

The catalogue's `updated` field is **2026-11-12**. The state/evidence/next-step values are shown as recorded at that date, not as live or reverified status. At that snapshot the 26 R-series rows were marked 14 implemented, 10 partial and 2 blocked. The table does not convert those labels into a claim that the requirements are currently complete.

The page is a concise index of the canonical R-series. The consolidated [Suggestions register](../ops-center/suggestions.html) separately holds 75 detailed candidate changes. A suggestion is not a completed requirement or evidence of a strategy result.

## Limits / flags

- The table is a source-linked readiness aid, not an independently refreshed data service. The catalog status date is visible on the page.
- Numeric clearance thresholds are proposals, and the page labels them as such. Existing sample-size numbers are not power analyses; each prospective study still needs a frozen rule and a justified sample window.
- Some sources are official for *context or method*, not for proof that a repository status or criterion has passed. The page exposes the registered source scope/limits per row.
- An official source link does not grant redistribution rights. The market-data, historical snapshot retention, and private raw-data policy remain blockers.
- No line, ROI, CLV, prop correlation, reward, or strategy result is newly claimed or computed by this task.
- The official Game Book's written-permission restriction is published as `DATA-USE-01` on the root [Flagged for Review](../flagged.html) page. This task only links to the official document; it does not copy or ingest its raw contents.
