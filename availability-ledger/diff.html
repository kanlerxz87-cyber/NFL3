How the diff is built

  • The depth side is the committed capture observed 2026-11-12T06:32:36.211205+00:00; it is not re-fetched, so the diff is reproducible from the repository.
  • The event side is the captured official reserve list and trade log, each row carrying its own source URL and the SHA-256 of the file it was read from.
  • A row is only shown when the published depth row and the official event name the same player at the same club. Nothing is matched on inference.
